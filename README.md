# Nova Home

## Обработка форм обратной связи

Формы отправляют данные в формате JSON в `server.php`. На сервере PHP должна быть
настроена функция `mail()`. По умолчанию письма отправляются на
`moroz2387moroz@yandex.ru`. Адрес получателя можно изменить переменной окружения
`CONTACT_EMAIL`. Переменная `MAIL_FROM` необязательна: если в ней указан корректный
адрес, он будет использован в качестве адреса отправителя.

Для локального запуска соберите сайт и используйте сервер с поддержкой PHP.
Не открывайте `index.html` напрямую и не используйте статический сервер Webpack
для проверки отправки форм:

```sh
npm run build
php -S 127.0.0.1:8000 -t . server/php-router.php
```

Откройте `http://127.0.0.1:8000`. При успешной отправке сервер возвращает JSON
и код HTTP 200. Некорректные данные формы возвращают HTTP 422. Если возникла
ошибка настройки или отправки почты, сервер возвращает ошибку и не сообщает,
что письмо было отправлено. Для загрузки прайса запустите JSON-server в отдельном
терминале командой `npm run start:api`.

## Локальный запуск админки

Webpack собирает отдельные файлы JavaScript для сайта (`dist/main.js`) и админки
(`dist/admin.js`). При входе админка обращается к middleware авторизации JSON-server
и переходит на `admin/table.html` только после успешной проверки. Страница таблицы
проверяет краткосрочную сессионную cookie с атрибутом `HttpOnly`.

Запустите фронтенд и API в разных терминалах:

```sh
npm run start
ADMIN_USERNAME=admin ADMIN_PASSWORD='change-this-password' npm run start:api
```

Откройте `http://localhost:8080/admin/`. API JSON-server будет доступен на порту
`4545` и использует базу `db/db.json`; Webpack проксирует API-запросы через
текущий адрес сайта, чтобы cookie авторизации работала и на `localhost`, и на
`127.0.0.1`. Задайте учётные данные через переменные окружения
`ADMIN_USERNAME` и `ADMIN_PASSWORD`; не используйте в примере пароль как есть.
Проверка логина и пароля выполняется GET-запросом; при успешном входе сервер
устанавливает сессионную cookie. Файл базы закрыт от прямой раздачи через Webpack
и встроенный PHP-сервер; публичная загрузка прайса выполняется через API.

Не используйте этот способ передачи пароля на рабочем сайте: параметры GET
могут сохраняться в истории браузера и журналах запросов. JSON-server и эта
авторизация предназначены только для локальной разработки.
