# Запуск JSON-server

Установите зависимости:

```sh
npm install
```

Задайте имя пользователя и пароль для входа в админку и запустите JSON-server:

```sh
ADMIN_USERNAME=admin ADMIN_PASSWORD='ваш-пароль' npm run start:api
```

Эту команду нужно выполнить в терминале из папки проекта.

Сервер запустится на `http://localhost:4545` и будет использовать базу
`db/db.json`.

JSON-server запустится и будет работать, пока команда выполняется в терминале. Не закрывайте это окно; сайт запускайте отдельно командой npm run start в другом терминале.
